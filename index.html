User Guide

What This Tool Does

Cubicles PQ Generator builds a complete cubicle-partition price quotation, room by room, directly in your browser — no installation needed. It automatically classifies every cubicle into Type A / B / C, calculates doors, panels, and packaging, and produces both a client-ready printed quote and an internal Excel order sheet with SKUs. Everything happens live on your computer — nothing is uploaded anywhere until you choose to save or print it.

1. Quote Details

Click Edit (or click anywhere on the summary) to open the editing window.

  • Left column: Company Name, Address, Contact — the client's information.
  • Right column: Attn., Tel., State/ZIP/Country.
  • Terms row: Reference, Quote Date, Revision, Incoterms, Currency (USD/EUR/ILS).

The card always shows a compact, read-only summary once you save — editing never clutters the main screen.

2. Global Defaults

Project Name identifies the job and is used later in file names. The fittings section sets Motor Cover, Wave On/Off Lock, HPL & Frame Color, and Auto/Manual. The Dimensions section sets Room Height, Door Width, and Divider Width — each field warns you if a value is unusual or out of range. The Imperial / Metric button instantly switches every dimension field to inches.

These values become the default for every new room — override them per room only when needed.

3. Adding a Room

Click + Add Room, then describe the room and choose a Cubicle Type:

  • Standard Cubicle Assembly — wall on one side, partition on the other.
  • Cubicle Door Assembly — thick walls between every cubicle.
  • Between Walls — walls on both outer sides.
  • Island Toilet Cubicles — thin partitions on both outer sides.
  • Urinal — no cubicles, just a fixture count.

The Classification Preview instantly shows how many A / B / C cubicles this produces.

4. Cubicle Layout — Live Floor-Plan Diagrams

Every cubicle gets its own architectural top-view diagram, drawn live:

  • Choose the door direction — RI, LI, RO, LO — and the swing arc updates instantly.
  • Check ADA Reinforced Door to label the cubicle "ADA" on its axis.
  • Check XL Cubicle to visibly widen that cubicle in the diagram.
  • Check Sliding Door to replace the swing arc with a directional slide arrow.

Each cubicle also shows its resulting Type (A / B / C) right above the drawing.

5. Managing Your Room List

  • Chips summarize everything at a glance — A/B/C counts, door directions, ADA, XL, Sliding, Outward.
  • The number stepper (− / +) sets how many identical rooms this line represents in the project.
  • The copy icon duplicates a room instantly; the trash icon deletes it (with confirmation).
  • Click anywhere on a room card to reopen it for editing.

6. Quote Summary & Pricing Controls

  • Every category (Auto/Manual A/B/C, add-ons, Urinal, Wooden Boxes, Shipping) is listed with an editable unit price.
  • Quantity-0 rows are dimmed and their price can't be edited — no confusion about what's actually being charged.
  • Add-ons Pricing has three modes: List separately, Combine into unit price, or Itemize per add-on — this controls how the printed quote presents ADA/XL/TOI/Sliding/Outward costs.
  • Round Prices can round every price up to a whole dollar or the nearest $5.
  • Notes typed here appear automatically at the bottom of the printed report.

7. Packaging & Shipping — Calculated Automatically

  • Every door, side wall, and depth partition in your rooms is converted into stacked 45 mm layers inside a wooden crate.
  • Box height is capped at 1500 mm — once layers exceed that, the tool automatically opens another box.
  • Total Weight is computed from real per-component weights (door, side wall, depth partition, extra parts).
  • Recommended Container compares your boxes against 20ft and 40ft standard containers and suggests the combination needing the fewest containers.
  • Show details reveals the full component and layer breakdown for engineering review.

8. Extra Pricing & Header Settings

  • Baran Headers swaps the printed report's letterhead to the Barantec Inc. (US) contact details, for orders shipped through that entity.
  • Wooden Boxes to price folds the crate cost evenly into every cubicle's unit price, instead of showing it as its own line.
  • Add-ons Pricing and Round Prices (also on this panel) control how the printed quote presents costs — see the Quote Summary section above.

9. PQ Print — The Client-Facing Quote

  • Page 1 is fixed marketing content — your letterhead, the STC Touchless overview, and the Type A/B/C/XL diagrams.
  • Page 2 is the full Price Quotation — every room's cubicles, add-ons, Urinal & Wooden Boxes, Shipping, and grand total.
  • PDF / Print opens your browser's print dialog with the correct file name pre-filled.
  • The exported file also embeds your entire project — reopen it later with Load to keep editing.

10. Exc. Details — The Internal Order Sheet

Click Exc. Details to download a formatted .xlsx workbook (this requires an internet connection, since it loads the Excel-generation engine on demand). The workbook has two sheets, and they are meant to be read together:

Order Report sheet starts with your Quote Details and Global Defaults, then the Order Entry table, followed lower down by the Rooms Summary table.

  • Order Entry simulates the actual line items you need to key into your ordering / production system — one row per SKU, per door direction, and per add-on combination (ADA / XL / TOI / Sliding / Outward), each with its own quantity and unit price. Every row gets a short reference code (R1, R2, R3…) so it can be pointed to from elsewhere.
  • Rooms Summary simulates the room-by-room details you need to enter alongside the order — for every room it lists Total Manual/Auto cubicles, Urinal count, RI/LI/RO/LO/Sliding direction counts, and ADA/XL counts.
  • The Order Entry Reference column in Rooms Summary is the link between the two tables: for each room, it lists exactly which Order Entry rows (by their R-code) belong to that room, and in what quantity — for example R2 × 4; R5 × 2 means 4 units of Order Entry row R2 and 2 units of row R5 both come from that specific room. This lets you trace every physical room back to the exact SKU lines that need to be ordered for it, and vice versa.

A second sheet, Price Quotation, mirrors the printed report's pricing table for easy sharing with finance or procurement.

11. Save, Load & Reset

  • Save downloads the same report-style file as PQ Print, with your full project data embedded inside it.
  • Load lets you pick that file back up later — every field, every room, every price restores exactly as you left it.
  • Nothing is stored on a server — your project only exists in the file you choose to save.
  • The red Reset button clears everything back to a blank project. It asks for confirmation first, and the action cannot be undone — use Save first if you want to keep a copy.

12. Dark Mode & Readability

The moon / sun icon in the top-right corner switches the whole interface between light and dark themes instantly. Dark mode keeps the same navy-and-blue palette as the Stern brand, just inverted for low-light comfort. Text throughout the app was deliberately sized for easy reading.
